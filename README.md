# MEJDZOR_BANK

Prosty projekt bankowości internetowej wykonany w **PHP, MySQL, HTML i CSS**.

## 📋 Opis

MEJDZOR_BANK to prosty system bankowy umożliwiający użytkownikowi zarządzanie swoim kontem oraz wykonywanie podstawowych operacji finansowych.

## ✨ Funkcje

* 🔐 Logowanie użytkownika
* 💰 Sprawdzanie stanu konta
* 💸 Przelewanie pieniędzy
* 💱 Wymiana pieniędzy na inne waluty
* 🗄️ Obsługa bazy danych MySQL

## 🛠️ Technologie

* PHP
* MySQL
* HTML
* CSS
* Apache

## 🚀 Instalacja

### 1. Serwer Apache

Przenieś wszystkie pliki projektu na serwer Apache.

Wymagana jest najnowsza wersja Apache.

### 2. Baza danych MySQL

1. Utwórz bazę danych o nazwie:

```sql
bank
```

2. Zaimportuj do niej plik `.sql` znajdujący się w projekcie.
3. Skonfiguruj połączenie z bazą danych w plikach projektu.

Wymagana jest najnowsza wersja MySQL.

## 📁 Uruchomienie

Po skopiowaniu plików na serwer Apache oraz skonfigurowaniu bazy danych `bank`, otwórz projekt w przeglądarce internetowej poprzez adres serwera.
